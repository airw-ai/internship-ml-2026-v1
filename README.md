# Internship ML Project 2026

Machine Learning internship project for training object detection and segmentation models.
Supports two training pipelines that share the same image dataset:

| Pipeline | Model family | Dataset format | Directory |
|----------|-------------|----------------|-----------|
| YOLO segmentation | Ultralytics YOLO 11 | YOLO (`.txt` labels) | `yolo/` |
| RF-DETR detection / segmentation | Roboflow RF-DETR | COCO JSON | `rf_detr/` |

## Project Structure

```
internship-ml-2026-v1/
├── yolo/                      # YOLO segmentation training pipeline
│   ├── train.py              # Main training script
│   ├── config.example.yaml   # Config template (80+ parameters)
│   ├── requirements.txt      # Python dependencies
│   ├── README.md             # Detailed training guide
│   └── README_RESULTS.md     # Training results interpretation
│
├── rf_detr/                   # RF-DETR detection/segmentation pipeline
│   ├── train.py              # Main training script
│   ├── config.example.yaml   # Config template
│   ├── requirements.txt      # Python dependencies
│   └── README.md             # Detailed training guide
│
├── dataset/                   # Datasets (download from Google Drive)
│   ├── convert_yolo_to_coco.py   # Convert YOLO dataset → COCO JSON for RF-DETR
│   ├── internship_dataset/       # YOLO format dataset
│   │   ├── data.yaml
│   │   ├── images/train/  images/val/
│   │   └── labels/train/  labels/val/
│   └── internship_dataset_coco/  # COCO format dataset (generated by converter)
│       ├── train/  _annotations.coco.json + images
│       └── valid/  _annotations.coco.json + images
│
├── weights/                   # Pretrained YOLO weights (download from Google Drive)
│   └── yolo11s-seg.pt
│
└── viz_annotations/           # Dataset visualisation tools
    └── visualize_yolo_dataset.py
```

## Getting Started

### Prerequisites

- Python >= 3.10
- CUDA-capable GPU (recommended)

### Setup

```bash
# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate       # Linux / Mac
# .venv\Scripts\activate        # Windows

# Install dependencies for the pipeline you want to use
pip install -r yolo/requirements.txt      # YOLO pipeline
pip install -r rf_detr/requirements.txt   # RF-DETR pipeline
```

### Download Dataset and Weights

Your instructor will provide Google Drive links. After downloading:

```
dataset/internship_dataset/   ← YOLO dataset
weights/yolo11s-seg.pt        ← Pretrained YOLO weights
```

### YOLO Training (Segmentation)

```bash
cd yolo
cp config.example.yaml config.yaml
# Edit config.yaml with your paths and settings
python3 train.py
```

See [yolo/README.md](yolo/README.md) for full documentation.

### RF-DETR Training (Detection / Segmentation)

1. **Convert the YOLO dataset to COCO format** (one-time step):

```bash
python3 dataset/convert_yolo_to_coco.py \
    --yolo  dataset/internship_dataset \
    --coco  dataset/internship_dataset_coco
```

2. **Configure and train**:

```bash
cd rf_detr
cp config.example.yaml config.yaml
# Edit config.yaml — set dataset_dir to ../dataset/internship_dataset_coco
python3 train.py
```

See [rf_detr/README.md](rf_detr/README.md) for full documentation.

### Dataset Visualisation

Before training, visualise your YOLO dataset to verify annotations:

```bash
cd viz_annotations
python3 visualize_yolo_dataset.py \
    --images ../dataset/internship_dataset/images/train \
    --labels ../dataset/internship_dataset/labels/train \
    --data-yaml ../dataset/internship_dataset/data.yaml
```

## Dataset Formats

### YOLO Format (used by `yolo/`)

```
dataset/internship_dataset/
├── data.yaml
├── images/
│   ├── train/  *.jpg
│   └── val/    *.jpg
└── labels/
    ├── train/  *.txt  (class_id x1 y1 x2 y2 ... xn yn — normalised)
    └── val/    *.txt
```

### COCO JSON Format (used by `rf_detr/`)

```
dataset/internship_dataset_coco/
├── train/
│   ├── _annotations.coco.json
│   └── *.jpg
└── valid/
    ├── _annotations.coco.json
    └── *.jpg
```

Use `dataset/convert_yolo_to_coco.py` to generate the COCO dataset from the YOLO dataset.
